# Zippin

> Zippin (vCognition Technologies Inc., San Francisco) builds a checkout-free, cashierless
> retail platform using computer vision, sensor fusion and machine learning. Shoppers enter
> with an app, credit card or campus credential, take what they want and leave; the platform
> bills the cart automatically. Its integration surface is the Zippin Gateway, an API
> framework Zippin says connects the platform to 25+ third-party systems — payment gateways,
> loyalty and gift providers, campus card systems, inventory, POS and self-service beverage
> hardware. Zippin publishes NO public developer portal, NO API reference and NO
> machine-readable API description; the live API host answers every request with HTTP 401.

## What is callable

- [Zippin Gateway (base URL)](https://api.getzippin.com/v1): live but fully credential-gated.
  Every path under /v1 returns HTTP 401 with
  {"error":{"type":"authentication_error","code":"authentication_failure",...}}. Access is for
  Zippin retailers and integration partners under contract. Probed 2026-09-05.
- The only public description of the API is one retailer help-center article: it is "a standard
  rest API with a nested JSON payload", pullable either for a given date or for change
  transactions since a point in time.

## Not published (checked 2026-09-05)

- No OpenAPI, Swagger, GraphQL, AsyncAPI, gRPC or WSDL contract on any Zippin host.
- No MCP server, no A2A agent card, no /llms.txt, no /apis.json.
- No SDK or client library in npm, PyPI, RubyGems or the company's GitHub presence.
  (npm "@zippin/react" and the GitHub org "zippin-io" are a DIFFERENT company — zippin.dev
  file uploads and zippin.io respectively — and are not Zippin's.)
- No status page, changelog, deprecation policy, pricing page, sandbox, CLI or Postman
  collection.
